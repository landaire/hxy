## Port summary

Reuse wholesale: hxy-plugin-host; settings model; settings/persist (SQLite); ipc.rs protocol (swap UiInbox); cli.rs; macos_open.rs core (swap repaint handle); ConsoleEntry/Severity + console_log logic; plugins/runner.rs (swap repaint arg); dispatch_plugin_outcome/install_mount_tab/retry_failed_mount cores.
Rewrite for gpui: settings_ui; console_ui/welcome_ui; panels/plugins.rs; mount rendering + temp-data queues (use typed fields/events instead); per-frame save_if_dirty (gpui: save on explicit mutation points or debounced observer).
Watch-outs: PartialEq dirty-check; dead language field (decide: wire or skip); mount VFS reads on UI thread; plugin-op drain must append new ops spawned during dispatch.
